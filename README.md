# TCG 箱買い期待値シミュレーター

TCG（トレーディングカードゲーム）の **「拡張パックの箱買い」** と **「シングル買い・未開封販売」** の期待値・損益を比較できる Web アプリです。
ビルド不要（HTML + Vanilla JavaScript + Tailwind CSS CDN）の単一ページ構成で、そのまま GitHub Pages にホスティングできます。

## 特徴

- 箱の購入価格・封入仕様・トップレアの相場から「自力で開封した場合の期待値（手残り）」を算出
- 指定した箱数を開けたときに、目当てのカードを **1枚以上自引きできる確率** を表示
- 未開封販売 / 開封してシングル売却 / シングル買い のどれが合理的かを自動判定
- 入力のたびにリアルタイム更新（判定結果は画面下部に固定表示）
- Local Storage への自動保存、JSON でのバックアップ・復元
- モバイルファースト（数値キーボード最適化、アコーディオン式のレアリティ枠）

- **日付・商品名つきの履歴保存**（前回比、再読込、CSV出力に対応）
- **ハイレア（◯箱に1枚）の確率指定**に対応

## 使い方

### 起動

- **ローカル**: `index.html` をブラウザで開くだけ（Tailwind の CDN 読み込みのためネット接続が必要）
- **GitHub Pages**: リポジトリの *Settings → Pages* で公開ブランチ（例: `main` / root）を選択

### 基本の操作手順

1. **ボックスの基本設定**: 購入価格、未開封のフリマ相場、開封する箱数を入力
2. **販売コスト設定**: フリマの手数料（%）と1件あたりの送料・梱包費を入力
3. **レアリティ枠を追加**（「＋追加」）し、以下を入力
   - レアリティ名（例: SR枠、AR枠）
   - 1箱あたりの確定封入枚数
   - そのレアリティの全種類数
   - 「＋カード追加」で特定の当たりカード（カード名・シングル相場）を登録
   - その他のカード（ハズレ）の平均相場
4. 画面下部の判定エリアで結果を確認（タップで詳細の開閉）

### 画面操作のヒント

- 枠のヘッダーをタップすると、中身の入力欄を折りたたみ/展開できます。閉じた状態でもその枠の期待値が見えます。
- 🗑 ボタンは各行の右端にあり、レアリティ枠・当たりカードを削除できます。
- 当たりカードの行は、親の枠に対してインデントと背景色で区別されています。

## 活用シナリオ

| シナリオ | 設定のポイント | 見るべき結果 |
| --- | --- | --- |
| **箱を買うか迷っている** | 購入価格と各枠を入力 | 開封期待損益、総合判定 |
| **未開封で転売すべきか開けるべきか** | 未開封フリマ相場を入力 | 未開封の実利益と開封期待損益の比較 |
| **目当てのカードだけが欲しい** | 目当てカードを当たりカードに登録し、箱数を調整 | 自引き確率。期待値割れなら「シングル買い推奨」 |
| **何箱開ければ狙えるか** | 開封する箱数を 1, 5, 10… と変える | 各カードの自引き確率 |
| **相場変動の影響を見たい** | トップレアの相場や手数料を変更 | 判定がどの価格で切り替わるか（損益分岐点） |
| **メルカリ以外で売る** | 手数料と送料を変更 | 売却コスト反映後の期待値 |
| **複数端末・弾ごとの管理** | エクスポートで弾ごとにファイルを保存 | 設定画面から復元して再比較 |

> 損益分岐点は、「開封期待損益 = 0」になる購入価格や相場を入力値を動かして探せます。
> 判定が切り替わる境界が分岐点です。

## 計算仕様

記号の定義:

| 記号 | 意味 |
| --- | --- |
| `P` | 1箱の購入価格 |
| `M` | 未開封ボックスのフリマ相場 |
| `f` | 手数料（%） |
| `s` | 1件あたりの送料・梱包費 |
| `n` | 開封する箱数 |
| `N` | そのレアリティの全種類数 |
| `k` | 1箱あたりの確定封入枚数 |
| `m` | 登録した特定当たりカードの数 |

### 1. 未開封販売の実利益

```
未開封の実利益 = (M − s) × (1 − f/100) − P
```

未開封のフリマ相場が未入力の場合は「相場未入力」と表示し、未開封は判定の候補から外れます。

### 2. 開封時のシングル売却期待値（手残り額）

**手順A: 実質価値の補正**（カードごと）

```
実質価値(x) = max(0, x × (1 − f/100) − s)
```

`x` は特定当たりカードの相場、またはその他カードの平均相場。
売却しても送料で赤字になるカードの価値は 0 円として扱います。

**手順B: 枠内期待値**

```
枠内期待値 = ( Σ当たりカードの実質価値 + 実質価値(その他平均) × (N − m) ) ÷ N × k
```

- 「その他」の枚数 `N − m` は 0 未満にならないよう 0 で下限処理します。
- `N = 0` の枠は計算対象外（0円）です。

**1箱あたりの開封期待値** = 全レアリティ枠の枠内期待値の合計

```
開封期待損益（1箱） = 1箱あたりの開封期待値 − P
開封期待損益（n箱） = 開封期待損益（1箱） × n
```

### 3. 個別カードを自引きできる確率

登録した当たりカードごとに、`n` 箱開封して **少なくとも1枚引ける確率**:

```
確率(%) = ( 1 − ((N − k) / N) ^ n ) × 100
```

- 1箱に同じ種類が複数入らない（`k` 枚はすべて別種）という前提の近似式です。
- `k ≥ N` の場合は 100% になります。

計算例: 全10種、封入1枚、3箱開封 → `1 − 0.9³ = 27.1%`

### 4. 総合判定

| 判定 | 条件 |
| --- | --- |
| 📦 **未開封推奨** | 未開封の実利益 > 0 かつ 未開封の実利益 ≥ 開封期待損益（1箱） |
| 🎉 **開封推奨（アド箱）** | 上記に該当せず、開封期待損益（1箱） > 0 |
| 🛒 **シングル買い推奨** | 上記以外（どちらでも利益が出ない＝箱買いは期待値割れ） |

判定は上から順に評価されます。

### 計算例

条件: 購入価格 5,400 円、手数料 10%、送料 210 円、SR 枠（全10種・1枚封入）、当たりカード 30,000 円と 10,000 円、その他の平均 100 円

| 項目 | 計算 | 結果 |
| --- | --- | --- |
| 30,000 円カードの実質価値 | 30,000 × 0.9 − 210 | 26,790 円 |
| 10,000 円カードの実質価値 | 10,000 × 0.9 − 210 | 8,790 円 |
| その他の実質価値 | 100 × 0.9 − 210 = −120 → 0 | 0 円 |
| 枠内期待値 | (26,790 + 8,790 + 0 × 8) ÷ 10 × 1 | 3,558 円 |
| 開封期待損益 | 3,558 − 5,400 | −1,842 円 |
| 判定 | 開封期待損益 ≤ 0 | シングル買い推奨 |

### 5. ハイレア（確率指定カード）の扱い

「SR枠は1箱に1枚だが、4〜5箱に1枚の割合でハイレアが混ざる」ケースに対応します。
当たりカードの **出現方式** を「確率指定（ハイレア）」にし、「何箱に1枚か」を入力します（4〜5箱に1枚なら `4.5`）。

追加の記号: `X` = 何箱に1枚か、`q` = 1箱あたりの出現確率 = `1 / X`（最大1）

- ハイレアは「その枠の `k` 枚のうちの1枚を置き換える」と考えます。1箱あたりの平均出現枚数が `q` になるので、通常排出に回る枚数は `k_eff = k − Σq` です。
- 確率指定カードは `N`（全種類数）に **含めません**。`N` は通常排出（均等）の種類数を入力してください。
- `Σq > k` の場合は、`Σq = k` になるよう按分します。

```
枠内期待値 = Σ( q × 実質価値(ハイレア) )
           + ( Σ通常当たりの実質価値 + 実質価値(その他平均) × (N − 通常当たり数) ) ÷ N × k_eff

ハイレアの自引き確率   = ( 1 − (1 − q) ^ n ) × 100
通常カードの自引き確率 = ( 1 − ((N − k_eff) / N) ^ n ) × 100
```

確率指定カードがない枠では `k_eff = k` となり、上記 2・3 の式と完全に一致します。

計算例: SR枠（`k = 1`、`N = 10`）に、50,000 円のハイレアが 4.5 箱に1枚（`q ≈ 0.222`）。その他は 0 円とすると、
期待値 = 0.222 × (50,000 × 0.9 − 210) = 約 9,953 円。5 箱開封で引ける確率は `1 − (1 − 0.222)^5 ≈ 71.5%`。

## データの保存・履歴

「いつ、どの商品を、どの条件でシミュレーションしたか」を残せます。

### 履歴の保存と確認

1. シミュレーション画面で **商品名** を入力（過去の商品名は入力候補に出ます）
2. 画面下部の **「④ この結果を履歴に保存」** で日付（既定は今日）とメモを入力し「💾 履歴に保存」。判定エリアの「💾 保存」ボタンでも保存できます（商品名が空なら入力を求められます）。
3. **「履歴」タブ** で一覧を確認
   - 商品名での絞り込み、新しい順/古い順の切替
   - 各項目に日付、商品名、判定、購入価格、開封期待値、期待損益、未開封の実利益、メモを表示
   - 同じ商品の1つ前の履歴との **開封期待値の差（前回比）** を表示
   - 「入力内容・確率の詳細」で、保存時の手数料・送料・各枠・各カード・自引き確率を確認
   - 「この条件を読み込む」で、その時点の入力内容をシミュレーション画面に再現（日付は今日に設定されるので、相場だけ更新して再保存できます）

履歴には「入力内容」と「保存時点の計算結果」の両方を保存するため、後で計算仕様が変わっても当時の結果を確認できます。

### 保存・バックアップ機能

| 機能 | 内容 |
| --- | --- |
| 自動保存 | 入力中の内容と履歴を Local Storage（キー: `tcg-box-sim-v2`）へ自動保存。旧 `v1` のデータは初回に引き継ぎます |
| エクスポート（JSON） | 履歴と入力中の内容をまとめて JSON でダウンロード |
| 履歴のCSV出力 | 日付、商品名、購入価格、期待値、期待損益、判定、メモなどを CSV 出力（Excel で文字化けしない BOM 付き UTF-8）。表計算で推移を見る用途向け |
| インポート | **マージ**（既定）: 既存履歴を残し、バックアップの履歴を追加。同じIDは上書き。入力中の内容は変更しない / **すべて上書き**: 履歴と入力中の内容を置き換え。旧形式（v1）のファイルは入力内容として読み込み |
| 入力リセット | 入力中の内容だけを初期化（履歴は残る） |
| 履歴の全削除 | 履歴をすべて削除（確認あり） |

## 注意事項

- 本ツールは、入力された相場と封入率が正しいことを前提とした期待値の目安です。実際の開封結果を保証するものではありません。
- 期待値は平均値であり、少数の箱では結果が大きくぶれます。
- 相場は日々変動します。購入前に最新の相場を入力してください。
- データはブラウザ内にのみ保存されます。端末の移行やブラウザのデータ削除に備え、エクスポートを活用してください。
